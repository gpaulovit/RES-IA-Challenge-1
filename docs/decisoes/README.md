# Registro de decisões de arquitetura

Uma ADR (*Architecture Decision Record*) é uma ficha curta que explica uma decisão importante, por que ela foi tomada, quem participou e quais consequências surgem. Ela evita que o time dependa da memória das reuniões.

## Como usar

1. Copie `modelo-adr.md` e use o próximo número: `ADR-002-nome-curto.md`.
2. Preencha contexto, decisão, alternativas, consequências, responsáveis e evidências.
3. Marque o status como `proposta`, `aprovada`, `substituída` ou `rejeitada`.
4. Registre a aprovação dos papéis responsáveis antes de a Engenharia implementar.

## Decisões existentes

- [ADR-001 — Campo canônico da alegação](ADR-001-texto-alegacao.md) — proposta para revisão conjunta de `dominio-dados` e `produto-decisao`.

## Resumo final da etapa

O ADR transforma uma conversa em uma decisão rastreável. Ele mostra o motivo, os participantes, os impactos e como saber se a escolha funcionou.
